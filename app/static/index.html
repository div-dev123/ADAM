Key Architectural Principle: Decoupled Intrinsic Value vs. Lifecycle State

In ADAM, a memory's importance score (0.0 to 1.0) represents its intrinsic informational value, calculated via deterministic Python heuristics (persistent markers, length, recency, recurrence). Its tier (Working, Short-Term, Long-Term, Archive) is its operational storage state governed by age, access counts, and compression.
